# 工具总控台

一页管住这套 DSH 安装里真正在跑的东西：每个 loader 条目、每个用户技能目录里的技能。

入口有两个，看到的是同一份列表：

- 「插件」页顶部的**总控台**标签
- 侧边栏的**工具总控台**面板

## 列表里有什么

| 行 | 来源 | 开关方式 |
| --- | --- | --- |
| 插件 | 宿主的插件管理器（`pluginManager.listPlugins()`） | 写 profile 的补丁层，和「插件」页写的是同一处 |
| 技能 | `~/.dsh/skills`、`~/.agents/skills` | `SKILL.md` 改名成 `SKILL.md.disabled`（可逆） |
| MCP 服务器 | profile 的 `cordis.patch.yml` 里 `@deepseek-ai/dsh-mcp-client` 条目 | 同插件（loader）；配置改的是该条目自己的 `config:` 块 |

每行会说明它是什么、现在开没开、不能开关时为什么不能：

- **官方**：`@deepseek-ai/*` 包和 loader 自己的 `cordis:*` 条目，随客户端一起装
- **宿主托管**：插件管理器、定时器、工具注册表这类不能从外部开关的条目
- **本插件**：这个面板自己。它不允许关掉自己，否则就没有地方再把它打开
- `#1`、`#2`：同一个模块被 loader 挂了多次时的序号

## MCP 服务器

MCP 行可以直接开关（和插件走同一个 loader 机制，保存即热加载），也可以在面板里新增、编辑、删除：

- **编辑配置**：只重写这一条自己的 `config:` 块，文件其余字节不动，保存后由宿主的 HMR 接上
- **测试连接**：按对话框里**当前填的值**（哪怕还没保存）临时起一个客户端，跑 `initialize` + `tools/list`，回报工具数量与耗时，然后杀掉进程；超时 12 秒，超时会连进程树一起结束
- **工具**：逐项勾掉某个工具，被勾掉的工具会从该 agent 的模型可见工具表里消失（不是调用时才拒绝）；这项状态存在本插件自己的 `state.json` 里

如果同时装了 Skill / MCP 面板，两边的禁用**取并集**：它禁的在这里只读显示，可以一键导入到本插件，反过来不会去改它的文件。

## 分组

分组里可以混放插件和技能。选中一个分组后，组名下面直接给**启用 / 禁用**两个按钮，整组成员一次开关；成员超过 20 个会先问一次。

「自动分组」按两轴把现有条目分成几组：先分角色（常开底座 / 专项任务），再分主题（上下文与记忆、界面与外观、创作与媒体、检索与抓取、开发与自动化、通知与集成）。左栏按角色分段，组可拖动排序，顺序持久化。它会先给预览，确认后才写；重跑只替换自动生成的那几组，手工建的组不动。



- **应用**：打开它列出的，关掉它没列的
- **只开启，不关闭**：只补开，不关任何东西

一次要改动超过 10 项时会先确认。

## 内置界面与关闭第三方

随客户端界面一起打包的官方行标着**内置界面**，开关是灰的：客户端不允许 profile 覆盖它们，面板也不会去写。点其它开关若被拒绝，会显示原因，而不是一句 failed。

工具条上的**关闭第三方**只拨开关、不卸载，动手前写一份回滚点到 `<状态目录>/rollback/<时间戳>.json`，顶栏随即出现**恢复**。

## 状态存在哪

```
<DSH_HOME>/tool-hub/state.json     默认 ~/.dsh/tool-hub/state.json
```


沙盒或测试 profile 想完全隔离，可以设两个环境变量：

```
TOOL_HUB_STATE_FILE=<dir>/tool-hub-state.json
TOOL_HUB_SKILL_ROOTS=<dir>/skills;<dir>/skills2   # Windows 用分号分隔
```

## 现在不做的事

- 只扫用户级技能目录，工作区里的 `.dsh/skills` 不属于「这套安装」，不在这里开关
- SSE 传输的服务器不能在面板里测试连接（stdio 与 streamable HTTP 可以）
- 没有终端界面，面板是 Web / Desktop 扩展

## 导入 dshmarket 分组

`dshmarket` 的分组存在 `<profile>/.dsh-market/state.json`。该文件有分组时，顶栏会出现导入按钮：面板把每个包名映射到它安装出来的 loader 行，再整组复制过来。这里已有同名的分组会被跳过而不是合并，所以重复导入不会产生重复项，也不会打乱你中途改过的分组；未安装的包按组列出并跳过，该文件本身只读不写。

## 与 dsh-skill-mcp-panel 共存

两个面板读的是同一份真值：技能是文件、MCP 是 patch 里的行。所以「同步状态」不是问题，**同时写**才是。装并启用了 dsh-skill-mcp-panel 时，本插件在重写 patch 前会先拿同一个 `<patch>.panel.lock`（独占创建、30 秒陈旧接管、最多等 5 秒），顶栏出现「兼容」徽标；它的工具屏蔽名单在这里只读并入（并集），绝不写它的文件。读操作不拿锁，列表与快照不会被拖慢。

手建分组放在「分组群」里：默认只有一个「默认分组群」，rail 底部能新建，标题上能改名或删除；删掉分组群时里面的分组会挪回默认分组群。自动分组只产出四个桶：官方 / MCP 服务器 / 通用 / 用户下载。
